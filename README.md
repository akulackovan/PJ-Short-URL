# PJ-Short-URL

Сервис сокращения ссылок — это инструмент, который позволяет пользователю сократить длинный URL, получить уникальную короткую ссылку и управлять её параметрами.

Пользователь может устанавливать лимит на количество переходов по ссылке и отслеживать её активность. После достижения лимита переходов или истечения заданного срока ссылка станет недоступной.

## Установка и запуск

### Требования

-   Java 17+\
-   Maven 3.6+

### Сборка и запуск

``` bash
# Клонирование репозитория
git clone <repository-url>
cd PJ-Short-URL

# Сборка
mvn clean compile

# Запуск приложения
mvn exec:java -Dexec.mainClass=org.example.Main

```

## Реализация

- Создание коротких ссылок
    Система принимает длинный URL и преобразовавыет его в короткую ссылку.
- Уникальные ссылки для каждого пользователя
- Лимит переходов
- Ограничение времени жизни ссылки
    Время жизни ссылки должно задаваться системой и ограничиваться определенным сроком (например, сутки). После истечения этого срока ссылка должна автоматически удаляться.
- Уведомления пользователя
    Уведомления пользователя происходит при входе в систему, после использования команды.
- Идентификация пользователя по UUID
    Каждый пользователь идентифицируется без авторизации с помощью UUID, который генерируется при первом запросе на создание короткой ссылки. Этот UUID используется для отслеживания всех действий пользователя с его ссылками. Реализован повторный вход по UUID.

## Управление ссылками

### Создание ссылок
| Команда | Параметры | Описание | Пример |
|---------|-----------|----------|--------|
| create| -l {ссылка} [-c {кол-во обращений}]| Создание новой короткой ссылки | create -l https://example.com -c 100 |

### Использование и отслеживание
| Команда | Параметры | Описание | Пример |
|---------|-----------|----------|--------|
| use| -s {короткая ссылка}| Переход по короткой ссылке (симуляция использования) | use -s clck.ru/7pNMLy |
| status-link| -s {короткая ссылка}| Просмотр статистики и информации о ссылке | status-link -s clck.ru/7pNMLy|

### Изменение и удаление
| Команда | Параметры | Описание | Пример |
|---------|-----------|----------|--------|
| change| -s {короткая ссылка} [-c {кол-во}][-t {время}]| Изменение параметров существующей ссылки | change -s clck.ru/7pNMLy -c 50|
| delete| -s {короткая ссылка}| Удаление короткой ссылки | delete -s clck.ru/7pNMLy|

- в команде change: время жизни ссылки (формат: чч:мм:ccили дд.мм.гггг чч:мм:cc), доступно только если в конфигурации установлено users.allow_time_change=true`

## Конфигурация

* data.file=data/data.json - Файл хранения данных

* users.save=true - Сохраняет UUID пользователя, даже если все ссылки для него удалены. При false` удаляет UUID при последующем входе за него или при следующем действии. Пользователю будут показаны уведомления о том, что ссылки были удалены, а после предложено получить новый UUID с помощью создания ссылки.
* users.need_login=false - При true для выполнения команд use и status-link пользователь должен зайти по UUID.
* users.allow_time_change=false - Для соответствия требованию 'время жизни задается программно' по умолчанию установлен запрет на изменение времени. При необходимости администратор может разрешить изменение времени через конфигурационный файл.

* links.check_by_code=true - Проверять ссылки по коду.
  * При true` проверяет только по коду без префикса (clck.ru/12345 и click.ru/12345 - одинаковые ссылки; если clck.ru будет заменен на click.ru, то ссылка с кодом 12345 не будет создана повторно).
  * При false` выбирает ссылки с определенным префиксом и проверяет код внутри них (clck.ru/12345 и click.ru/12345 - разные ссылки).
* links.clear_time=6000 - Интервал очистки неактивных ссылок в секундах.
* links.count=5 - Количество переходов по умолчанию.
* links.count_notification=3 - Количество переходов, с которых начнутся уведомления.
* links.time=43200 - Время жизни ссылки при создании в секундах.
* links.time_notification=1800 - Время в секундах до уведомления об истечении срока ссылки.
* links.validation=^https?://.+ - Регулярное выражение для валидации исходных ссылок.
* links.link=clck.ru/ - Префикс короткой ссылки.
* links.size=6 - Размер ссылки.
* links.alphabet=ABCDEFGHIJKLMNOPQRSTUVWXYZ1234567890abcdefghijklmnopqrstuvwxyz - Символы для создания короткого кода.
* links.max_try=1000 - Максимальное количество попыток при создании генерации сокращенной ссылки.

## Пример работы

```bash
# 1. Создание ссылки
create -l https://github.com -c 2
# Вывод: короткая ссылка и UUID пользователя

# 2. Статус
status
# Вывод: UUID пользователя, количество ссылок 1

# 3. Использование ссылки
use -s [короткая_ссылка]
# Вывод: открытие браузера, уведомление о количестве переходов

# 4. Редактирование ссылки
change -s [короткая_ссылка] -с 10

# 5. Просмотр состояния
list
# Вывод: список ссылок 1 ссылка с количеством переходов 10

# 6. Выход из системы
logout

# 7. Вход в систему
login -u [UUID]

# 8. Статус
status
# Вывод: UUID пользователя, количество ссылок 1

# 9. Завершение работы
exit

```
